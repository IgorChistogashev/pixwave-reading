# Android-сборка

## Текущий статус

Собран тестовый файл `PIXWAVE-android-arm64.apk`: 29 233 933 байта (29,2 МБ), Godot 4.5.1, ABI `arm64-v8a`, landscape, без разрешений Internet и Record Audio. APK прошёл экспорт Godot, проверку ZIP-целостности и проверку подписи v2/v3. Он подписан временным тестовым ключом; ключ не включён в проект и не подходит для публикации в магазине. Файл ещё не установлен и не запускался на Android-устройстве или эмуляторе. APK распространяется отдельно от архива исходников.

Цель **до 30 МБ** достигнута для этого тестового APK. В сжатом ARM64-шаблоне Godot один движок занимает около 23,2 МБ ещё до ресурсов игры, поэтому включение дополнительных ABI резко увеличивает размер. В проекте для экспорта исключаются скриншоты документации, тестовые файлы, скрипты разработки и исходный PNG фона; фон преобразуется в меньший JPG и импортируется в ETC2/ASTC, чтобы Android не тащил настольную текстуру. Без такого мобильного импорта APK получался 30 720 776 байт; после включения ETC2/ASTC он стал 29 233 933 байта.

30 МБ — цель для первого установочного файла, а не отдельная квота каждого будущего уровня. Каждый отдельный APK повторно содержит движок. Для продолжения проекта лучше держать общую игру и уровни в одной сборке либо позднее исследовать отдельные пакеты контента; текущая версия остаётся офлайн-доступной.

## Сборка на машине с настроенным SDK

1. Установите Godot **4.5.1 Standard** и шаблоны экспорта этой же версии.
2. Установите OpenJDK 17 и компоненты Android SDK, которые требует официальная документация Godot для версии 4.5: Android Command-line Tools, Platform Tools, Build Tools, Android Platform, NDK и CMake.
3. В Godot откройте **Editor → Editor Settings → Export → Android** и укажите Java SDK Path и Android SDK Path.
4. Откройте **Project → Export** и выберите `Android arm64 test`. Экспортировать нужно как APK с пресетом `arm64-v8a`; для теста на 32-битных устройствах потребуется отдельная сборка с ABI `armeabi-v7a`, размер которой будет другим.
5. Подпишите тестовую сборку локальным ключом. Не передавайте тестовый ключ, пароль или production-ключ в репозиторий. Для публикации создайте и надёжно сохраните отдельный release-ключ.
6. Измерьте размер APK и проверьте его подпись, пакет, разрешения, запуск без сети, сенсорное управление, звук, сохранение и прохождение. Текущий APK уже проверен как архив и по подписи, но установка и игровая проверка на устройстве ещё нужны.

Официальная инструкция: https://docs.godotengine.org/en/4.5/tutorials/export/exporting_for_android.html

## Ручная установка и проверка

Для личного теста перенесите APK на Android arm64-устройство и подтвердите установку из выбранного источника. Затем отключите интернет и пройдите уровень: начало, сбор обрывков, соединение МА, станции МО/МУ, встреча с хранителем, завершение и сохранение звезды. Отдельно проверьте два одновременных касания и возврат в игру после сворачивания.

Сборка на Mac и проверка архива APK не заменяют установку и пробу на реальном Android-устройстве. Не сообщайте о такой проверке, если её не проводили.
