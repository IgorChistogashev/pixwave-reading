# Устройство первого уровня

- `main.tscn` — точка входа.
- `scripts/main.gd` — небольшой сборщик мира, переходов задания и UI. Для одного уровня Learning и UI пока находятся в этом файле; отдельной инфраструктуры модулей нет.
- `scripts/player.gd` — Game Core: физика, разгон, короткие окна для прыжка, анимация восьми кадров Sprite2D.
- `scripts/world.gd` — фон, игровые фонари и ворота, спутник, свечение, коллекционные огоньки и одноразовые частицы. Camera2D следует за героем. Физические тела по-прежнему создаются в main.gd.
- `content/level_01.json` — Content: идентификатор, буквы, слог, подсказка, путь к звуку. Случайных упражнений нет.
- `scripts/progress.gd` — Progress: версия схемы, загрузка и сохранение JSON в user://.
- `scripts/speech_evaluator.gd` — Speech: будущий контракт `is_available`, `evaluate`, `cancel`, сигнал `evaluated`. Единственный текущий результат — unavailable. Этот класс не подключён к проверке ответов, разрешение микрофона не запрашивается.
- `scripts/music.gd` — тихая зацикленная музыка, плавное затихание в панелях и пауза при сворачивании; переключатель хранится в прогрессе.
- `tools/compose_music.py` — воспроизводимый синтез оригинального трека без зависимостей.
- `assets/audio/ma.wav` — временное аудио, ограничения описаны в ASSETS.md.
- `tests/smoke.gd` — проверка сквозного сценария.

Состояния: путь → задание → подтверждение взрослого → открытый проход → финиш. Выход из задания оставляет кнопку МА для возврата. Звезда выдаётся за прохождение с взрослым, максимум одна. Отказы в подтверждении не используются; кнопка повторного прослушивания не обозначает ошибку ребёнка.

Данные: completed, stars, practice_requests и confirmations. Последние два числа — накопленные действия интерфейса, не количество реальных речевых попыток. Пройденный МА — знакомство, а не подтверждённо изученный слог. Истории записей, персональных данных и сети нет. При повреждённом JSON используются начальные значения. Сохранение не транзакционное: резервирование и миграции потребуются перед расширением.

## Следующие шаги

1. Прослушать и заменить временный звук, обсудить с педагогом демонстрацию звукового слияния. Проверить реальные касания и читаемость на телефоне.
2. Собрать APK, провести короткий тест по CHILD_TEST.md. Исправить управление и подсказки по наблюдениям.
3. Решить, сохраняет ли ребёнок интерес и читает ли МА вне игры. При трудностях упростить управление или заменить движение одним касанием; не добавлять новые уровни автоматически.
4. Только после этого выделить LearningSession из main.gd, добавить валидатор контента и выбор уровней. Обсудить с педагогом БА/ПА/НА и мягкость М в МИ: нельзя просто менять картинку гласной при неизменном звуковом образце.
5. Распознавание исследовать отдельно на согласованном наборе детской речи. Будущие результаты контракта: accepted, retry, uncertain, unavailable; uncertain никогда не означает «ребёнок ошибся». До измерений не выбирать движок по обещаниям качества. Сохранить ручной и безречевой путь; хранение аудио по умолчанию выключено.

Надёжность распознавания слогов не исследовалась. iOS предполагается через штатный экспорт Godot, но сборка, подпись и сенсорное поведение не проверялись.

## Сюжетная версия «Потерянное письмо»

`story.gd` хранит состояние текущего приключения: intro → collect → bridge → guardian → boss_read → delivered. Там же находятся две детерминированные встречи, проверка прыжка сверху/дистанции импульса, пауза между импульсами хранителя и его безопасная волна. `main.gd` координирует сюжет с UI и чтением, а `world.gd` рисует открывающийся мостик и окружение. Случайный сбор светлячков из предыдущей версии удалён.

Чтение имеет контекст bridge/boss/bonus: первое знакомство запускает образец; финальное повторение ждёт самостоятельной попытки или кнопки подсказки; бонус использует chunks и audio из JSON. Прогресс завершения выдаётся за финальное МА с подтверждением взрослого, а не за победу световыми импульсами. МАМА необязательно и хранится отдельной отметкой без дополнительных звёзд.

`panel_open` блокирует центральное действие; `story.paused` и `world.frozen` останавливают сюжетные движения. Микрофон не подключён. Состояние короткого приключения не сохраняется между запусками; сохраняются только достижения и наблюдения интерфейса.

Полировка: UI-анимации находок и короткие сообщения создаются локально через Tween, без новых зависимостей. Camera2D сглаживается экспоненциальной интерполяцией. Основное окно синхронно останавливает Story, World и голос при потере фокуса; при возврате учитывается открытая учебная панель. Световой импульс имеет короткую визуальную паузу отдельно от секундной паузы хранителя. Эти паузы относятся только к игровым действиям, не к чтению.

## Маршрут с тремя слогами

Состояние route между bridge и guardian последовательно читает checkpoints из JSON. Каждая остановка задаёт card, guided, x, kind и при необходимости glyph/blob_x. Одинаковая логика создаёт новый учебный эпизод или повторение; новые гласные выдаются конкретной кляксой. Коллизии отдельных станций открываются только после подтверждения текущего задания. Review хранит порядок финального повторения. ContentCatalog проверяет целостность ссылок на карточки и аудиоресурсы. Игровые координаты по-прежнему задаются в единицах фиксированного мира.

В card_activity сохраняются guided_confirmations и practice_confirmations по идентификатору карточки. Практика означает режим показа, а не доказанную самостоятельность: ребёнок может пользоваться подсказкой. Полноценной методической адаптации и генерации упражнений нет.
