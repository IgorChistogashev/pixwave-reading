# Участие

Для начала обсуждения достаточно GitHub Issues; Discussions можно включить при создании репозитория. Репозиторий пока не опубликован.

В задаче указывайте ожидаемое поведение, фактическое, версию Godot, устройство и способ повторения. Не прикладывайте имена, фото, голос и другие данные детей. Предложения оцениваем по пользе для чтения, доступности, безопасности, интересу и стоимости реализации.

Изменения должны быть небольшими. Перед PR: импорт в Godot 4.5.1, smoke-тест, ручной проход, описание фактически выполненных проверок. Новый учебный материал должен содержать источник звука, права на распространение и отметку о педагогической проверке. Не добавляйте платные API, аналитику, рекламу и скрытый сбор данных. Распознавание не должно заменять альтернативный способ прохождения.

Вклад в код — под MIT; для звуков и рисунков указывайте отдельное происхождение и разрешение. Не переносите персонажей и материалы чужих игр.
